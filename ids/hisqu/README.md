# /hisqu/

Permanent identifiers for the HisQu project (<https://www.hisqu.de/>).

| IRI | Redirects to | Owner |
| --- | --- | --- |
| `https://w3id.org/hisqu/` | <https://www.hisqu.de/> | HisQu |
| `https://w3id.org/hisqu/dmw/process` | the latest release of the DMW process vocabulary, as Turtle | DMW |
| `https://w3id.org/hisqu/dmw/process/<n>` | release `<n>` of that vocabulary, as Turtle | DMW |
| `https://w3id.org/hisqu/data/` | reserved for the hosted DMW server's data | DMW server operators |
| `https://w3id.org/hisqu/ontology/` | reserved for the core ontology modules | HisQu ontology team |
| `https://w3id.org/hisqu/rg/` | reserved for Repertorium Germanicum data | RG data maintainers |
